# 截图使用

按 **Ctrl + Alt + A**，点击侧边栏顶部截图按钮，或使用托盘“截图”。可在设置中单独修改截图热键；发生占用时保留原热键并显示提示。

顶部工具栏默认出现在鼠标所在显示器。截图开始后侧边栏暂时隐藏；取消、复制或保存完成后恢复。

| 操作 | 用法 |
|---|---|
| 窗口吸附 | W，然后将鼠标移到窗口并点击；也可直接拖动框选 |
| 矩形框选 | A，然后拖动；支持跨显示器 |
| 调整选区 | V，拖动选区内部移动、边缘或角点改变尺寸 |
| 矩形标注 | R，在选区内拖动绘制空心矩形 |
| 画笔 | P，在选区内拖动绘制，单击绘制一个点 |
| 颜色/粗细 | 选择色块，以及 2/4/8/12/20 px 笔宽；已绘制笔画保留原样 |
| 撤销/重做 | Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y |
| 保存 | Ctrl+S，选择 PNG 路径；取消对话框会继续编辑 |
| 复制 | Ctrl+C 或 Enter，成功后结束；剪贴板占用时可重试 |
| 隐藏工具栏 | Tab，便于选择或标注工具栏下的画面 |
| 取消 | Esc，不导出图片 |

重新选择“窗口吸附”或“矩形框选”会清除当前选区和标注。调整选区只改变裁剪范围；标注保持在冻结桌面的原位置。

HDR 显示器使用 FP16 scRGB 采集，结合 Windows 的 SDR 白电平归一化并压缩高光，保存为带 sRGB 标记的普通 PNG。输出可以在普通显示器和常见聊天软件中使用，不是保留原始 HDR 动态范围的文件。混合 HDR/SDR 屏幕分别转换，输出像素尺寸按物理像素计算。
